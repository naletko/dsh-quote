# Quote for DeepSeek Harness

Выделите текст в переписке и вставьте его в поле ввода цитатой в markdown — так, как это делает Codex, и не потеряв уже набранный черновик.

Рядом с выделением появляется маленькая ненавязчивая кнопка **Цитировать**. Нажмите её или сочетание `Ctrl+Shift+.` (`Cmd+Shift+.` на macOS) — и выделенный текст окажется в поле ввода в виде:

```
> первая строка цитаты
> вторая строка цитаты
```

Между цитатой и уже набранным текстом остаётся одна пустая строка. Цитата именно **дописывается** к черновику и никогда его не заменяет.

---

## ✨ Возможности

- **Цитирование выделенного.** И сообщения ассистента, и свои — всё, что можно выделить в переписке.
- **Черновик не теряется.** Вставка идёт через собственные действия поля ввода `captureInsertion()` / `insertText()`: одна отменяемая правка в позиции курсора. Если этот путь недоступен, текст читается из поля ввода и цитата дописывается к нему — плагин никогда не перезаписывает набранное.
- **Сначала клавиатура.** `Ctrl+Shift+.` в Windows и Linux, `Cmd+Shift+.` в macOS; сочетание можно перезаписать в настройках.
- **Исчезает, когда должна.** Схлопнутое выделение, клик в пустоту, `Esc`, прокрутка, изменение размера окна, переключение вкладки или сессии — кнопка убирается.
- **Без ложных срабатываний.** Выделения внутри `input`, `textarea` и `contenteditable`, включая само поле ввода сообщения, игнорируются.
- **Аккуратный текст.** Выделение обрезается по краям, `CRLF` нормализуется, подряд идущие пустые строки схлопываются в одну строку цитаты, длина ограничивается настройкой.
- **Родная тема.** Все цвета — токены DSH (`--dsw-alias-*`) с запасными значениями, поэтому кнопка и карточка настроек выглядят правильно и в тёмной, и в светлой теме. Учитывается `prefers-reduced-motion`, есть `aria-label` и обводка фокуса.
- **Русский и английский.** Язык интерфейса берётся из `document.documentElement.lang` (`ru*` — русский, иначе английский).
- **Без зависимостей и сборки.** Один файл host-половины и один файл browser-половины.

## 📦 Установка

Выберите способ, который подходит вашему варианту DSH.

### В приложении Desktop

1. Откройте **Plugins**.
2. Нажмите **Add plugin** и введите `dsh-quote` — или абсолютный путь к этой папке, если ставите локальную копию.
3. Включите бандл, если он приехал выключенным. Карточка настроек появится на странице самого плагина.

### Из командной строки

```bash
dsh plugin --profile web add dsh-quote
```

Чтобы поставить локальную копию вместо опубликованного пакета, укажите абсолютный путь:

```bash
dsh plugin --profile web add /абсолютный/путь/к/dsh-quote
```

### Из исходников

Собирать и устанавливать ничего не нужно:

```bash
git clone https://github.com/naletko/dsh-quote.git
cd dsh-quote
node test/metadata-check.mjs
node test/quote-logic-check.mjs
```

## 🚀 Использование

1. **Выделите** текст в переписке — часть сообщения, абзац или несколько абзацев.
2. Нажмите **Цитировать** рядом с выделением или используйте горячую клавишу.
3. Блок-цитата **добавится в поле ввода** после пустой строки, остальной черновик не изменится.

Типичный сценарий: выделить абзац ответа, с которым вы не согласны, процитировать его и дописать свой комментарий ниже.

## ⌨️ Горячая клавиша

| Платформа | По умолчанию |
| --- | --- |
| Windows, Linux | `Ctrl+Shift+.` |
| macOS | `Cmd+Shift+.` |

В настройках сочетание хранится в переносимом виде `Mod+Shift+.`, где `Mod` — это `Ctrl` в Windows и Linux и `Cmd` в macOS. В карточке настроек можно записать любое сочетание хотя бы с одним модификатором; буквенные клавиши сопоставляются по физическому коду клавиши, поэтому сокращение работает и на нелатинской раскладке.

## ⚙️ Настройки

Карточка находится на странице плагина в разделе **Plugins** и за кнопкой **Configure** у строки.

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| **Включить цитирование** | включено | Выключает кнопку и горячую клавишу, не удаляя плагин. |
| **Добавлять строку-атрибуцию** | выключено | Закрывает цитату дополнительной строкой `> — цитата` (по-английски `> — quote`). |
| **Максимальная длина цитаты** | `4000` | Сколько символов брать из выделения; допустимо `200`–`20000`. Более длинное выделение обрезается по символу. |
| **Горячая клавиша** | `Mod+Shift+.` | Нажмите на поле и введите нужное сочетание. **Вернуть по умолчанию** возвращает исходное. |

Карточка показывает живой предпросмотр того, что именно попадёт в поле ввода.

Настройки читаются и записываются через собственный роут плагина `GET`/`POST /api/dsh-quote/config` и хранятся файлом `dsh-quote-config.json` в домашнем каталоге DSH — в `$DSH_HOME`, если переменная задана, иначе в `~/.dsh`. Копия в `localStorage` нужна только для того, чтобы поле ввода знало настройки при первой отрисовке.

## 🔒 Приватность

- **Нет доступа в сеть.** Host-половина плагина обслуживает один локальный роут и больше ничего; наружу она не обращается.
- **Нет секретов, телеметрии и аналитики.** Настраивать нечего, кроме четырёх параметров отображения.
- **Только локальные файлы.** Единственный записываемый файл — `dsh-quote-config.json` в `$DSH_HOME`.
- **Только локальные запросы.** `/api/dsh-quote/config` отклоняет всё, что заведомо пришло не с loopback, и не принимает тела больше 16 КиБ.
- **Ничего не покидает страницу.** Выделенный текст форматируется в браузере и вставляется в поле ввода; плагин его никуда не отправляет, не логирует и не сохраняет.

## 🔄 Обновление

Плагин обновляет себя сам: в карточке **Настройки → Плагины → Quote** есть раздел **«Обновления»** — он
спрашивает у GitHub ревизию ветки, показывает установленную версию рядом с версией на `main`, перечисляет,
что изменилось, и одной кнопкой отдаёт закреплённый коммит менеджеру плагинов харнесса. После этого обновите
страницу; если версия не сменилась — перезапустите приложение (host-половина грузится только при старте).

Если в сборке нет менеджера плагинов, раздел печатает строку для ручной установки через
**«Плагины → Добавить плагин»**: `github:naletko/dsh-quote`.

## 🧩 Требования и совместимость

- **Ядро DeepSeek Harness `0.2.0-rc.2`** (веб-клиент приложения Desktop или сессия в браузере).
- Используются слоты `conversation.input.right` (списочный — одиночный `conversation.input.activity` намеренно не занимается, иначе плагин вытесняет микрофон голосового плагина), `plugins.bundle.config` и `plugins.row.config`, а также действия поля ввода `captureInsertion()` / `insertText()` / `setDraft()`.
- **Windows, macOS и Linux.** Пути строятся через `node:path`, горячая клавиша понимает `metaKey`, платформенных API из одной ОС не используется.
- Ни зависимостей из npm, ни сборщика, ни шага сборки.

## 🧪 Тесты

```bash
node --check index.js client.js
node test/metadata-check.mjs      # exports, иконка, локали, регистрация слотов
node test/quote-logic-check.mjs   # правила цитирования, горячие клавиши, настройки, позиционирование
```

`client.js` — не модуль: он регистрируется в браузерном загрузчике модулей DSH. Поэтому оба теста загружают его через поддельный `window.__ModuleLoader__` — ровно так же, как это делает браузер, — и вызывают собственные функции плагина через хук `__test`. Host-половина — обычный ES-модуль, он импортируется напрямую.
